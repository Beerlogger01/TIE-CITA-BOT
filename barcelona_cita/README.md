# Barcelona TIE Cita

Локальный помощник записи на отпечатки TIE в Barcelona для двух профилей. Один Chromium, безопасная передача текущей вкладки человеку через Home Assistant Ingress/noVNC, Telegram и резервный SMTP.

Слоты не резервируются простым сохранением сессии. Подтверждение выполняет человек на портале. См. [DOCS.md](DOCS.md) для установки и ограничений.
