Подтверждение записи

После ручного завершения на портале укажите номер и дату из подтверждения. Add-on проверит их наличие на текущей странице. Новый экран может потребовать доработки распознавания.

Заявители

Данные хранятся только в add-on. В уведомления отправляется только имя профиля.

Настройки

Минимум — 15 минут между проверками для всех заявителей вместе. Четверг 14:45–15:25 и утро 06:00–09:00 рассчитываются по Europe/Madrid. Наблюдение о четверге не является официальным расписанием.

Допустимые даты и отделения сохраняются как предпочтения для человека. В этой версии они не приводят к автоматическому выбору или подтверждению.
