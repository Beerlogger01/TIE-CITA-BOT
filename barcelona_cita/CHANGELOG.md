# 0.3.0

- Одна основная кнопка мониторинга, рабочий стол и настройки; ручная проверка перенесена в дополнительные инструменты.
- Раздельные признаки процесса, загруженного портала, пригодной, пустой и зависшей страницы. Пустой браузер после технического сбоя освобождается автоматически.
- Единое восстановление с отменой задачи и ограниченным временем закрытия Chromium. Найденная возможная запись защищена до явного подтверждения потери сессии; интервал и backoff сохраняются.
- Отключение noVNC освобождает ручное управление; доступен возврат к мониторингу без перезапуска.
- Подписки Telegram в личном чате через одноразовые приглашения, команды /start, /status, /stop, /help; по умолчанию до двух получателей.
- SQLite сохраняет подписчиков, отписки и update_id; старые Chat ID и параметры уведомлений сохранены.
- Приём команд включается отдельно для выделенного token, с проверкой webhook и остановкой при конфликте getUpdates. Ошибка Telegram не останавливает поиск.

# 0.2.2

- Открытие noVNC больше не отменяет активную проверку: просмотр ожидает результат, WebSocket отклоняет преждевременный захват управления. Явная пауза по-прежнему сохраняет текущую вкладку.
- Показаны шаг проверки, состояние автоматического расписания и время разрешённого ручного запуска.
- Добавлена тестовая отправка уведомлений с ограничением раз в минуту; Telegram предназначен для исходящих сообщений.
- Раздельные безопасные коды ошибок загрузки портала, DNS, TLS и соединения, без записи персональных данных.

# 0.2.1

- Исправлена установка в Home Assistant OS: удалён устаревший `build.yaml`, не проходивший валидацию Supervisor из-за ссылки на образ с digest. Debian теперь закреплён непосредственно в `FROM`, поэтому legacy `BUILD_FROM` не заменяет его Alpine-образом.
- CI на amd64 и ARM64 проверяет сборку с аргументами и метками Supervisor, включая подставленный Alpine `BUILD_FROM` для воспроизведения прежней ошибки.
- Добавлены метки образа Home Assistant и проверка Debian-базы при запуске тестового контейнера.

# 0.2.0

- Первая версия Home Assistant add-on: два профиля, расписание Europe/Madrid, конечный автомат.
- Сохранение текущей вкладки, остановка автоматизации и ручной доступ через Ingress/noVNC.
- Telegram с URL-кнопкой, SMTP, HA уведомления и диагностические состояния.
- Локальные HTML-фикстуры, тесты ограничений и передачи управления, CI для нативного ARM64.
- Окончательное подтверждение только человеком; реальные последующие экраны требуют проверки.
